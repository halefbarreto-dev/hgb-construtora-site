# Arquivos de mídia

Adicione nesta pasta os arquivos usados pelo site:

- `logo-hgb.jpg` — logo/marca d'água da HGB.
- `construcao-casa-moderna-2.mp4` — vídeo do banner de acompanhamento de obra.

Enquanto esses arquivos não forem adicionados, o restante do site continua funcionando; o vídeo exibirá a imagem de capa e a marca d'água usa um fallback visual.
